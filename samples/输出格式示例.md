# 输出格式示例（虚构内容）

> ⚠️ **本文件是虚构示例，不是真实视频的处理结果。**
>
> 为了让示例可公开，这里编了一个假视频「三分钟学会煮一碗不坨的面」，
> 按 pipeline 的实际输出格式走了一遍。
>
> **真实使用时，知识库里存的是「知识点 + 问答对 + 关键参数」三节，
> 不含视频原文（合规设计，见 README「合规处理」一节）。**

---

## 一、元数据头

每个文档的第一块是元数据，让检索时每段都带来源标识：

```
【三分钟学会煮一碗不坨的面】
平台: douyin / 0000000000000000000
时长: 168.5 秒
作者描述: 煮面总是坨？三个关键点，看完就会 #家常菜 #煮面技巧
```

**⭐ 为什么每块都要带标题前缀**：Dify 自动分段会让多个视频的片段互相串台
（实测：「电商详情页生成工作流」这个查询命中了长视频里讲「调色台」的片段）。
加上标题后，每段的向量里都含标题关键词，跨视频区分度明显提高。

---

## 二、知识点（入库保留）

```
## 知识点
- 煮面不坨的三个关键：水量足、火候大、时间短
- 水量至少是面条体积的 5 倍，水少了面汤会变稠、面条互相粘连
- 下面后保持大火，水一直处于沸腾状态；小火慢煮会让面条表面糊化
- 细面煮 2 分钟、宽面煮 3 分钟，到点立刻捞出
- 捞出后过一遍冷水或拌少许油，能进一步防止粘连
- 加盐的时机是水开后下面之前，每升水约 5 克；过早加盐会延长煮沸时间
```

**⭐ 这一节属于「思想」**（方法论、参数关系），不受著作权保护，
而且是检索时最有用的一部分。

---

## 三、问答对（入库保留）

```
## 问答对
Q: 煮面为什么总是坨？
A: 通常是三个原因之一：水太少（面汤变稠）、火太小（没有持续沸腾）、
   煮太久（表面糊化）。三个都对上，面就不容易坨。

Q: 水要放多少？
A: 至少是面条体积的 5 倍。水少了面汤会变稠，面条互相粘连。

Q: 细面和宽面分别煮多久？
A: 细面 2 分钟，宽面 3 分钟，到点立刻捞出。

Q: 盐什么时候放？
A: 水开后、下面之前放，每升水约 5 克。

Q: 捞出来之后还要做什么？
A: 过一遍冷水，或者拌少许油，进一步防粘连。
```

**⭐ 为什么问答对也对检索有帮助**：
问答对是「问题 → 答案」形式，**跟用户提问的形式天然匹配**，
向量相似度比原文还高。实测下来，问答对经常排在检索第一位。

---

## 四、关键参数（原文摘录，限量保留）

```
## 关键参数（原文摘录）
以下是从原视频里摘出的含具体数值/参数的句子，供核对事实用：
- 水量至少是面条体积的 5 倍
- 细面煮 2 分钟、宽面煮 3 分钟
- 每升水约 5 克盐
- 水开后下面，全程保持大火
```

**⭐ 为什么这一节可以保留**：
著作权法保护「表达」，**不保护「事实」**。数值、参数名、型号是事实，
不受保护；而它们恰恰是检索最有用的信息（用户常问「放多少」「煮多久」）。

**⭐ 三条限制**（防止变相保留全文）：
1. 只摘含数值或已知参数名的句子，纯观点句不摘
2. 总长封顶 700 字
3. 明确标注「原文摘录」，不冒充自己的话

## 五、不存什么（合规关键）

```
## 校对稿       ← ❌ 不入库
```

**「校对稿」是视频的完整原文**，属于受保护的「表达」，
**不入库** —— 哪怕只给一家公司内部用，使用主体是商业实体也算商业使用。

**控制开关**：环境变量 `KEEP_SECTIONS`
```bash
# 默认（合规）：只留 知识点 + 问答对 + 事实摘录
# 不设这个变量即可

# 回退（三节全存，仅本地测试用）
export KEEP_SECTIONS="校对稿,知识点,问答对"
```

## 七、实测数据（真实数字，非虚构）

| 视频时长 | 全流程耗时 | 识别速度 |
|---|---|---|
| 27 秒 | 15.1 秒 | 6.86 倍 |
| 87 秒 | 31.6 秒 | 4.58 倍 |
| 145 秒 | 61.1 秒 | 3.34 倍 |
| 11 分 37 秒 | 147.2 秒 | 5.58 倍 |

**⭐ 规划时间时按「每小时音频 15–18 分钟」保守估算**，
不要按倍率线性推算 —— 识别速度受语速、停顿、背景音影响，不只看时长。

**⭐ 合规改造前后的对比**（同一个视频）：

| | 改造前 | 改造后 |
|---|---|---|
| 知识库总字数 | 9087 字 | 6133 字 |
| 含他人原文的段 | 每个文档 2–3 段 | **0** |
| 检索通过率 | 5/6 | **7/8** |

**⭐ 意外收获**：去掉原文后检索反而更准了 ——
问答对的命中得分（0.489）比原文（0.455）还高。
